# prepare data
This picks up after the DEG analysis.  It prepares the data for modeling using top N most significant genes.

`python prepare.py <path to local deg results folder> <top_n_sig>`

# Generate prompts

Make the prompts to run through c2s

`python generate_prompts_1k_deg.py <path to local prepared data folder>`

# Run Cell2Sentence

Run cell2sentence and save embeddings locally on the prompts.  Note: this takes a while

`python run_c2s.py <path to local prompt folder>`

# Run modeling

Predict early vs mid vs late on embeddings generated by c2s

`python run_modeling.py <path to cell2sentence embeddings>`
